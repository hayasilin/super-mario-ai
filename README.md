# Super Mario AI
* This is a repo to train AI to play Super Mario Bros by following the tutorial from Pytorch official website.
* This repo is using pip to manage Python dependencies and runs on Mac mini M4.

# Reference Source
* [Train a Mario-playing RL Agent](https://pytorch.org/tutorials/intermediate/mario_rl_tutorial.html)
* [Github Repo](https://github.com/yfeng997/MadMario)

# Setup Command Line
```bash
conda create -n SuperMarioAI python=3.8

conda activate SuperMarioAI

pip install -r requirements.txt

python main.py
```
